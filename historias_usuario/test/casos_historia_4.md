# TC-007 - Agregar producto al carrito

## Objetivo
Verificar que un producto pueda agregarse correctamente al carrito.

## Precondiciones
- El usuario ha iniciado sesión.

## Datos de prueba
- Producto: Café Latte
- Cantidad: 2

## Pasos
1. Abrir el menú.
2. Seleccionar un producto.
3. Indicar la cantidad.
4. Agregar al carrito.

## Resultado esperado
El producto aparece en el carrito con la cantidad y el total actualizado.

## Resultado obtenido
Pendiente.

## Estado
Pendiente.

## Notas / Evidencias
Pendiente.

# TC-008 - Agregar cantidad inválida

## Objetivo
Verificar que el sistema no permita cantidades inválidas.

## Precondiciones
- Usuario autenticado.

## Datos de prueba
Cantidad: 0

## Pasos
1. Seleccionar un producto.
2. Ingresar cantidad 0.
3. Agregar al carrito.

## Resultado esperado
El sistema muestra un mensaje de error y no agrega el producto.

## Resultado obtenido
Pendiente.

## Estado
Pendiente.

## Notas / Evidencias
Pendiente.
