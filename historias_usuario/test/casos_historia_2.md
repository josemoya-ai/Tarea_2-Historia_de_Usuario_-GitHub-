# TC-003 - Inicio de sesión exitoso

## Objetivo
Verificar que un usuario registrado pueda iniciar sesión con credenciales válidas.

## Precondiciones
- El usuario debe estar registrado.

## Datos de prueba
- Correo: usuario@test.com
- Contraseña: Password123*

## Pasos
1. Abrir la pantalla de inicio de sesión.
2. Ingresar el correo electrónico.
3. Ingresar la contraseña.
4. Presionar "Iniciar sesión".

## Resultado esperado
El sistema permite el acceso y mantiene la sesión activa.

## Resultado obtenido
Pendiente.

## Estado
Pendiente.

# TC-004 - Inicio de sesión con contraseña incorrecta

## Objetivo
Verificar que el sistema rechace credenciales inválidas.

## Precondiciones
- El usuario debe existir.

## Datos de prueba
- Correo: usuario@test.com
- Contraseña: Incorrecta123

## Pasos
1. Abrir la pantalla de inicio de sesión.
2. Ingresar el correo.
3. Ingresar una contraseña incorrecta.
4. Presionar "Iniciar sesión".

## Resultado esperado
El sistema muestra un mensaje de error y no permite el acceso.

## Resultado obtenido
Pendiente.

## Estado
Pendiente.

Pendiente.
