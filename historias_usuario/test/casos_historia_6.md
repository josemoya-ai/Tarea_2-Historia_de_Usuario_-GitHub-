# TC-011 - Consulta del historial de pedidos

## Objetivo
Verificar que el usuario pueda consultar sus pedidos anteriores.

## Precondiciones
- Usuario autenticado.
- El usuario tiene al menos un pedido registrado.

## Datos de prueba
No aplica.

## Pasos
1. Iniciar sesión.
2. Abrir la opción "Historial de pedidos".

## Resultado esperado
El sistema muestra las órdenes con fecha, productos y monto total.

# TC-012 - Usuario sin pedidos registrados

## Objetivo

## Precondiciones
- Usuario autenticado.
- El usuario no tiene pedidos registrados.
